1. Descripción del Proyecto Desarrollé el portafolio web profesional y responsivo bajo la marca fallencode para exhibir mis habilidades como Desarrollador Full-Stack e Ingeniero de Inteligencia Artificial (GENESIS CABA). El proyecto fusiona una estética disruptiva de fanzine vintage punk y cyberpunk retro (modo oscuro con acentos en morado eléctrico y rosado fucsia neón) con los estándares más rigurosos de la ingeniería web moderna: HTML5 semántico, CSS3 modular, Bootstrap 5 y JavaScript puro (ES6+).

2. Bitácora de Desarrollo: Proceso Paso a Paso


•	Paso 1: Conceptualización e Identidad de Marca

o	Definición de Marca: Establecí el seudónimo fallencode junto con la insignia de rol dev_punk // GENESIS CABA para reflejar una identidad técnica transgresora pero profesional.

o	Paleta Cromática y Atmósfera: Seleccioné una base de modo oscuro profundo (#0b0713, #06040a) combinada con un morado eléctrico (#3b1f5e) y un rosado fucsia neón (#ff2a85) para generar contraste visual de alto impacto.

o	Diseño Conceptual (UI/UX): Integré elementos visuales inspirados en los fanzines analógicos (marcos tipo Polaroid con cinta adhesiva superior, divisores de papel rasgado y tipografías estilo terminal retro como VT323 y Syne).

•	Paso 2: Arquitectura y Maquetación Estructural (index.html)

o	Estructura Semántica: Construí un layout basado en HTML5 utilizando etiquetas semánticas (<nav>, <header>, <section>, <footer>) para garantizar accesibilidad y optimización para motores de búsqueda (SEO).

o	Navbar Flotante: Integré una barra de navegación fija con efecto de desenfoque de fondo (backdrop-filter) y enlaces de acceso rápido a las secciones clave.

o	Sección Hero: Diseñada con una grilla responsiva de Bootstrap 5. Del lado izquierdo coloqué el estado del sistema, el título principal y la biografía; del lado derecho, un marco Polaroid con una etiqueta de imagen limpia (src="tu-foto.jpg") lista para insertar mi fotografía fácilmente.

o	Stack Tecnológico con Devicon: Estructuré una sección de tarjetas con efectos de neón al pasar el cursor, integrando logotipos oficiales de Devicon para tecnologías clave (JavaScript, Python, React, Node.js, Bootstrap, Git).

o	Sección de Proyectos con Filtros: Habilité una grilla modular de proyectos acompañada de botones interactivos para alternar entre categorías (Full-Stack, Inteligencia Artificial, Vintage Punk).

o	Footer y Redes Sociales: Configuré un pie de página minimalista que incluye de manera exclusiva los íconos oficiales de Facebook, Instagram y YouTube, junto con el año dinámico de derechos reservados.

•	Paso 3: Estilos Visuales y Efectos Especiales (style.css)


o	Variables CSS Personalizadas: Declaré variables raíz para mantener la coherencia absoluta de los colores fucsia y morado en todo el documento.

o	Efectos Cyberpunk: Añadí una capa superpuesta de líneas de escaneo (scanlines) mediante gradientes CSS para otorgar una textura visual retro-futurista.

o	Micro-interacciones: Programé transiciones suaves (transition: all 0.3s ease), sombras de neón dinámicas (box-shadow) y efectos de elevación (hover lifts) en tarjetas y botones.

•	Paso 4: Programación de la Lógica Interactiva (script.js)


o	Filtrado Dinámico de Proyectos: Desarrollé un script en JavaScript puro que escucha los clics en los botones de filtro, evaluando los atributos de categoría (data-category) de cada tarjeta para mostrarlas u ocultarlas de forma fluida.

o	Botón "Volver Arriba": Implementé un escuchador de eventos en el scroll de la ventana (window.scrollY) que activa la visibilidad del botón flotante de retorno al superar los 300 píxeles de desplazamiento.

o	Navegación Fluida (Smooth Scroll): Normalicé el comportamiento de los enlaces ancla para que la transición entre secciones sea suave y elegante.





•	Paso 5: Subida y Despliegue en GitHub


o	Inicialicé el control de versiones en mi entorno local dentro de la carpeta del proyecto y registré el primer conjunto de cambios (commit).

o	Creé un nuevo repositorio público en mi cuenta de GitHub bajo el nombre fallencode-portfolio.
